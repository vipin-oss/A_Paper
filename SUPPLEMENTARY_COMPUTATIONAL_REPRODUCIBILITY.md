# Supplementary document: computational reproducibility record

**Paper A — backward-wave conversion of a guided mode at the free edge of a
flexoelectric piezoelectric-semiconductor plate.**

This document is the computational record of the article. It was moved out of
the article in round 14 because a mathematical research article states its
method and the evidence that the method is implemented correctly, and leaves
the tooling to a supplement. Nothing here changes a reported result: the
constants, the model, the boundary conditions, the solver, the root
classification, the peak, the coupling results, the normalisation, the energy
balance and the synthetic status of the parameters are those of the manuscript.

---

## 1. What is reproduced, and by what

Every number, table entry and curve in the paper is generated by the programs
listed below from one material record. No value is transcribed by hand, and no
plotted quantity is computed inside the plotting code: one program solves the
physics and writes the stored datasets, a second reads those datasets and only
draws.

| Path | Role |
| --- | --- |
| `a0/materials.json` | material constants with provenance tags; the model cannot start without it |
| `paper_a_study/model.py` | spectral plate solver: spatial and temporal routes, edge matching, power and dissipation |
| `paper_a_study/build_figure_data.py` | solves the physics and writes every CSV/JSON used by the figures |
| `paper_a_study/generate_final_figures.py` | reads the CSVs and renders the ten vector PDFs |
| `paper_a_study/figure_style.py` | shared typography, colour-blind/grayscale-safe palette and dash/marker cycles |
| `paper_a_study/peak_search.py` | staged search that locates and classifies the maximum of the backward share |
| `paper_a_study/peak_identity_audit.py` | five artefact probes: reference-plane rescaling, incident-mode identity, mode separation, conditioning, flux scale |
| `paper_a_study/certify_peak.py` | degree-refinement study at four fixed wavenumbers; certifies values, never searches |
| `paper_a_study/reclassify_csv.py` | re-derives the admissibility flags of the figure CSVs without re-solving |
| `paper_a_study/modal_flux_audit.py` | eigenvector-rescaling and degree-refinement proof of the reported share |
| `paper_a_study/mechanism_controls.py` | matched controls and the branch-consistent coupling sweep |
| `paper_a_study/corner_assessment.py` | corner-band energy share and incident-wavenumber regression behind the limitations |
| `paper_a_study/convergence_audit.py` | successive changes of the share between Galerkin degrees 14 and 30 |
| `paper_a_study/quadrature_audit.py` | the same configurations under Gauss–Legendre rules of 64 to 256 nodes |
| `paper_a_study/verify_dimensions.py` | dimensional and constitutive audit, including the strain-gradient contraction test |
| `paper_a_study/quasistatic_check.py` | the retardation, relaxation and screening ratios of the electric-model section |
| `paper_a_study/flexo_control.py` | measured flexoelectric contribution to the reported numbers |
| `paper_a_study/phase_speed_audit.py` | phase-speed and wavenumber reconciliation between text and solver |
| `paper_a_study/test_model.py` | the automated checks (52 tests) of the verification section |
| `paper_a_study/claim_audit.py` | registry check, stale-value guard and figure-order check over the manuscript |
| `paper_a_study/claims.json` | the registry: every quoted number, the string that carries it, and its source |
| `paper_a_study/mutation_tests.py` | deliberate defects injected into the solution path, each expected to be caught |
| `paper_a_study/reference_constants.json` | frozen reference values and literature bands used by the material regression test |
| `paper_a_study/run_all_checks.py` | the whole battery, one log |
| `paper_a_study/figure_data/*.csv` | the eleven data files behind the figures |
| `paper_a_study/figure_data/*.json` | panel-source map, figure manifest, field metrics, refinement study, controls, corner assessment |
| `Paper_A_Final_Submission/main.tex`, `sections/`, `figures/` | the manuscript and its ten vector PDFs |

The archive deliberately contains no `.npy` or `.npz` files. Two legacy scripts
superseded by `build_figure_data.py` / `generate_final_figures.py` used such
caches; they are not part of the reproduction path and are not shipped, so a
clean extraction reproduces the results without any binary intermediate.

## 2. Commands

From a clean extraction, with a Python 3.11 environment containing `numpy`,
`scipy` and `matplotlib`:

```bash
# exit status 0 = every check passed
python paper_a_study/run_all_checks.py            # battery, ~15 min
python -m unittest paper_a_study.test_model -v    # 52 tests, ~25 s
python paper_a_study/convergence_audit.py         # degree sequence, ~10 s
python paper_a_study/quadrature_audit.py          # node sequence, ~10 s
python paper_a_study/claim_audit.py               # manuscript vs registry, ~1 s
python paper_a_study/mutation_tests.py            # the gates must fail, ~1 s
python paper_a_study/build_figure_data.py         # CSV/JSON, ~6 min
python paper_a_study/reclassify_csv.py            # flags, ~1 s
python paper_a_study/certify_peak.py              # refinement, ~30 s
python paper_a_study/peak_search.py               # staged search, ~6 min
python paper_a_study/peak_identity_audit.py       # artefact probes, ~2 min
python paper_a_study/generate_final_figures.py    # ten PDFs, ~20 s
python paper_a_study/modal_flux_audit.py          # rescaling proof
python paper_a_study/mechanism_controls.py        # controls, ~1 min
python paper_a_study/corner_assessment.py         # corner check, ~20 s
python paper_a_study/phase_speed_audit.py         # 0 = text agrees with solver
```

Order matters only in that `generate_final_figures.py` needs the CSV files, and
that `peak_identity_audit.py` and `claim_audit.py` read the records written by
`peak_search.py` and `certify_peak.py`. `certify_peak.py` and
`reclassify_csv.py` are independent of each other and of the plotting step. All
scripts resolve paths relative to their own location (`__file__`) and to the
repository root, so they run from any working directory.

Exit statuses are part of the interface. `run_all_checks.py`,
`reclassify_csv.py`, `certify_peak.py`, `generate_final_figures.py`,
`modal_flux_audit.py`, `mechanism_controls.py` and `corner_assessment.py` return
0 when their own checks pass and non-zero when one fails. `phase_speed_audit.py`
returns 0 when every quantity quoted in the electric-model section agrees with a
recomputation from the material file; a non-zero status there is a defect
report, not a normal outcome. The last full run is recorded in
`validation/verification_log.txt`.

## 3. Environment used for the reported runs

Python 3.11.2, NumPy 2.4.6, SciPy 1.17.1, Matplotlib 3.11.2. The solver uses
only dense linear algebra (`numpy.linalg`, `scipy.linalg.svd`, the generalised
eigenproblem), so results are reproducible across BLAS implementations to
round-off. The only stochastic element is the random state used inside two
verification tests; no production result depends on it.

Times New Roman is not installed in the build container. DejaVu Serif is the
documented, licence-clean fallback; no font binary is redistributed, and the
choice is recorded in the figure manifest.

## 4. What the automated checks contain

The verification statements of the article's solution section are executed as a
suite of 52 tests, which includes the regression tests that pin the material and
reference constants. Beyond the physics checks, the suite guards against errors
of *identification* rather than of *solution*:

* Two tests guard the configuration labels of the corner study: they assert that
  it identifies its cases by the incident wavenumber ($K_0=0.7362$ at the
  operating point, not $K_B=0.2452$), and that its stored operating-point share
  agrees row by row with the independent refinement study to $10^{-9}$.
* Four tests guard the location of the maximum, written as solver evaluations
  rather than stored expectations: the refined wavenumber must beat every
  sample of the coarse raster; the incident root returned there must lie within
  $2\times10^{-3}$ of the requested value and more than $0.2$ away from the
  backward target; the net attenuation exponent of the two partner modes must
  rescale the partition by exactly that factor; and the stored classification
  must remain a local maximum of the declared window with the stored headline
  equal to a fresh solve to nine places.
* Three tests concern the plane at which a share is quoted. Every edge-plane
  ratio is obtained from the reference-plane value with the single transform
  $R(L_{\text{to}})=R(L_{\text{from}})\exp[2(\Imag K_i-\Imag K_B)(L_{\text{from}}-L_{\text{to}})]$
  and every script calls the same implementation of it. The first test checks
  the identities of that transform analytically (identity at equal planes,
  composition over two steps, invariance when both attenuations vanish); the
  second solves the same scattering problem at $L=0,10,15,20$ thicknesses and
  requires the value reconstructed at the edge to be independent of the plane
  used, which it is to $2\times10^{-16}$; the third compares the stored
  edge-plane fractions produced by the search, the matched controls and two
  figure datasets and requires agreement to $10^{-6}$ relative.
* `mutation_tests.py` injects 15 defects (single-mode decay in place of the
  two-mode ratio, sign reversal of the backward wavenumber, stale caption
  values, wrong figure order, and others); each must be caught by the check
  that is supposed to catch it, and 15/15 are.

## 5. Provenance and integrity

* `a0/materials.json` records every constant twice: once as a value and once as
  a provenance tag. The tags distinguish literature values, values derived
  through the Einstein relation, and parameters chosen for this study. The file
  also records the values deliberately **not** assigned — the flexoelectric
  tensor of a specific specimen, the strain-gradient tensor of a specific
  specimen, the coupling tensor of any specimen, the sample doping, the sample
  thickness and the surface properties. These are the quantities for which no
  defensible literature value was found; they are marked as such rather than
  filled with a plausible number.
* `figures/` holds the ten vector figures; `figure_data/figure_manifest.json`
  maps each figure to its data file and to the script that produced it, and
  `figure_data/figure_panel_sources.json` maps each panel to the columns of the
  corresponding CSV, so any single panel can be traced back to the solve that
  produced it.
* The distributed archive carries a `MANIFEST.json` with one entry per file, a
  SHA-256 for the archive itself, and a static-validation record of the
  manuscript (environment balance, cross-reference resolution, citation
  resolution, presence of every included figure).

## 6. What is not reproducible here

* The visual appearance of the figures is reproducible only up to the
  Matplotlib and font versions, because the layout is tuned to the reported
  versions.
* The manuscript was validated statically — environment and bracket balance,
  cross-reference resolution, citation-key resolution and the presence of every
  included figure were checked by script. No TeX engine was available in the
  build environment, so the PDF was **not** compiled there and no typeset output
  is claimed. A reader who builds the manuscript must treat the typeset output
  as unverified and the content as statically validated.
